# UV-Vis Data Plotter

Standalone plotting tool for UV-Vis spectroscopy data generated by the Ocean Optics UV detector.

## Features

- **Real-time monitoring**: Auto-updates plot as new data is written to CSV
- **Multi-wavelength support**: Plots absorbance at all target wavelengths
- **Standalone operation**: Works independently of the main UV detector GUI
- **Command-line interface**: Easy to launch and configure

## Usage

### Basic Usage

```bash
python uv_detectors/uv_plot_gui.py --csv-file path/to/uv_data.csv
```

### With Custom Update Interval

```bash
python uv_detectors/uv_plot_gui.py --csv-file path/to/uv_data.csv --interval-ms 5000
```

### Demo Mode (No File)

```bash
python uv_detectors/uv_plot_gui.py
```

This creates and plots sample data automatically.

## CSV Format

The CSV file should have the following format:

```
Time(s),409.0,450.0,500.0
0.0,0.095,0.904,0.398
3.0,0.172,0.866,0.414
6.1,0.190,0.830,0.407
...
```

- First column: `Time(s)` - elapsed time in seconds
- Subsequent columns: wavelength values (e.g., `409.0`, `450.0`) - absorbance measurements

## Testing

### Generate Test Data

```bash
python simulate_uv_experiment.py [duration_seconds] [interval_seconds]
```

Example:
```bash
python simulate_uv_experiment.py 60 5
```

This generates `simulated_uv_data.csv` with synthetic UV-Vis data.

### View Test Data

```bash
python view_uv_simulation.py
```

Opens the plotter with the simulated data file.

## Integration with Main GUI

To integrate this plotter into the main methods GUI (similar to status monitors):

1. Import the function in `methods_gui.py`:
   ```python
   from uv_detectors.uv_plot_gui import open_uv_plot_monitor
   ```

2. Add a button to open the UV plot window:
   ```python
   ttk.Button(frame, text="Open UV Plots", 
              command=lambda: open_uv_plot_monitor(self, uv_csv_path, 10000))
   ```

## Notes

- The plotter automatically detects all wavelength columns in the CSV
- Default auto-update interval: 10 seconds (10000 ms)
- Use Stop/Start Auto-Update button to control automatic refreshing
- Click "Refresh Now" to manually update the plot
